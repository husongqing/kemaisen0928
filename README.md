# 科迈森在线培训学习平台 · 微信小程序原型

A high-fidelity WeChat Mini Program UI prototype for **科迈森 (KMS Medical)** online training platform, built as a single-file HTML deliverable.

品牌规范：**A 方案 · 科技青环**（深海军蓝 `#061B3A` + 科技青 `#00C9FF → #0066FF`）
参考需求：科迈森在线培训学习平台 方案梳理 0928.docx

## 直接打开

直接用浏览器打开 `weapp.html` 即可：

- **电脑端**：显示 390×844 手机外壳 + 全部 31 个页面，可逐屏交互
- **手机端**：自动铺满屏幕，隐藏外壳（响应式断点 480px）

## 包含页面（31 屏）

启动页 / **双入口页** / **科迈森商城** / 登录 / 注册 / 忘记密码 / 首页 / 课程中心 / 课程详情 / 播放页 / 培训活动 / 活动详情 / 活动报名 / **确认支付** / **支付结果** / 资讯 / 资讯详情 / 个人中心 / **会员中心** / **我的订单** / 我的课程 / 我的报名 / 收藏 / 消息 / 平台介绍 …

## 本次新增功能（0928 → 1010）

1. **启动后双入口页** — 启动页加载完成后进入入口页，提供「科迈森学习平台」「科迈森商城」两个入口；点击学习平台进入原小程序，点击商城跳转「科迈森商城」小程序界面（演示）。
2. **培训活动报名收费** — 活动详情展示报名费（¥1,980）；报名表单提交后进入订单支付页，支持 **微信支付**（密码弹层 → 支付成功，后台标记支付状态）与 **现场支付**（订单转「待支付」，现场缴费后由后台标记）。已缴费学员由后台勾选开通配套视频观看权限，可在「我的订单」查看。
3. **年卡会员购买** — 会员中心展示权益对比（游客 / 报名学员 / 年卡会员），¥399/年开通后解锁全部视频；入口位于个人中心顶部卡片、课程详情权限卡、活动详情权益卡。
4. **视频权限分层** — 免费试看 / 报名学员（后台配置开通指定章节）/ 年卡会员（全部视频）；课程详情新增「观看权限」卡与锁定章节示例（点击弹出解锁方式）。
5. **视频防录屏** — 播放页叠加动态溯源水印（姓名 + 手机号 + 实时时间，横向滚动）+ 右上角「防录屏 · 溯源水印已开启」徽标；播放中切后台触发防录屏监测提示；分享/外传被限制。

## 重新构建

```bash
python3 build_weapp.py     # 重新生成 weapp.html
```

构建脚本会从 `assets/` 读取 18 张真实图（从 sudh.net 内容接口抓取），把它们编码成 base64 内联进 HTML，输出一个完全自包含的单文件。

## 资源素材

`assets/` 目录下：

- `course-1..6.jpg` — 课程卡片缩略图（6 张真实手术/讲座帧）
- `act-1..6.jpg` — 培训活动海报（6 张 4:3 真实海报）
- `news-1..6.jpg` — 资讯栏目封面（6 张真实幻灯/学术截图）

如需替换素材，直接覆盖同名文件，重新跑 `build_weapp.py` 即可。

## 技术栈

- 单文件 HTML + 内联 `<style>` / `<script>`
- 无任何外部依赖
- 所有图片 base64 内联 → 离线可用、无 CDN 依赖
- Playwright 验证：响应式外壳、真实封面渲染、23 条主流程（含入口页 / 报名支付 / 会员购买 / 商城跳转 / 防录屏水印），0 报错
